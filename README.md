# Qvnp

Linux only tty/terminal media player.

---

## Features

- Сustomizable video and audio playback, rendering right in terminal "pixels".

---

## Requirements

- Linux
- python3

---

## Installing/Updating

Download install.sh, then:

```bash
cd ~/Downloads/ ; chmod +x install.sh ; sudo ./install.sh
```

Or just with one command:
```bash
curl -fsSL https://raw.githubusercontent.com/quadakr/qvnp/main/install.sh | sudo bash
```
---

## Launch

```bash
qvnp yourfile.mp4
```
